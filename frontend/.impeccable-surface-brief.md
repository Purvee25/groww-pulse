# Groww Pulse Frontend — Surface Brief

**Mode:** Operate (users complete a task: see ranked alerts, add stocks, respond to thesis prompts)  
**Platform:** Web (React + TypeScript + Vite)  
**Target Devices:** Desktop, tablet, mobile (responsive)  
**Theme:** Dark (OLED-optimized); light mode available

## Visual Strategy

The frontend is a financial watchlist dashboard. Users come to:
1. **See ranked alerts** — stocks sorted by attention score (HIGH/MEDIUM/LOW)
2. **Respond to thesis prompts** — connect market moves to their investment thesis
3. **Manage watchlist** — add/remove symbols, mark as caught up

Design must earn trust through **clarity, precision, restraint**. No unnecessary motion, color, or complexity. Every UI element serves a purpose. Typography hierarchy guides the eye to what matters: the attention score and price change since checkpoint.

## Design System

### Color Palette

**Dark Theme (Default, OLED):**
- **Brand:** #5367FF (Groww purple) — CTAs, badges, focus states
- **Text:** #F8FAFC (light primary), #CBD5E1 (secondary), #94A3B8 (muted), #64748B (dim)
- **Surface:** #0E1223 (card bg), #1A1F35 (hover), #252E42 (active)
- **Background:** #020617 (canvas/OLED black)
- **Borders:** #1E293B (default), #334155 (light on hover)
- **Semantic:**
  - Price Up: #10B981 (green)
  - Price Down: #EF4444 (red)
  - Priority HIGH: #DC2626 (red)
  - Priority MEDIUM: #F59E0B (amber)
  - Priority LOW: #10B981 (green)

**Light Theme (Fallback):**
Inverted tones, same semantic meanings. Defined via `@media (prefers-color-scheme: light)` and `:root[data-theme="light"]`.

### Typography

**Font:** IBM Plex Sans (financial standard, Google Fonts, 300–700 weights)

**Scale:**
- Hero/Page Title: 3.5rem (weight 700, line-height 1.1, letter-spacing -0.02em)
- Section Heading: 2rem (weight 700)
- Card Title: 1.25rem (weight 600)
- Body: 1rem (weight 400, line-height 1.6)
- Small/Label: 0.875rem–0.75rem (weight 500)

### Motion

- **Button hover:** 200ms ease-out, translateY(-1px), shadow lift
- **Button press:** Instant, scale(0.97)
- **Focus ring:** 2px solid white, 2px offset
- **Input focus:** Brand color border + 3px glow
- **Card transitions:** 200ms smooth on border + background
- **Respect prefers-reduced-motion:** All transitions → 0.01ms when enabled

### Shadows (Depth System)

- **Subtle (sm):** 0 1px 2px 0 rgba(0, 0, 0, 0.3)
- **Medium (md):** 0 4px 6px -1px rgba(0, 0, 0, 0.4), 0 2px 4px -1px rgba(0, 0, 0, 0.3)
- **Large (lg):** 0 10px 15px -3px rgba(0, 0, 0, 0.5), 0 4px 6px -2px rgba(0, 0, 0, 0.3)

## Surface Layers

### 1. Landing Page (Public Hero)
- Header: Logo + [Login] [Sign up]
- Hero: "What changed enough to matter?" + value prop + "Get started" CTA
- Three-step flow cards (numbered badges, shadows, hover effects)
- Differentiator box: comparison (volatile +5% MEDIUM vs calm +2.5% HIGH)
- Footer: "Groww Pulse · [Log in]"

### 2. Auth Pages (Login / Register)
- Centered card (400px max-width)
- Email + password inputs (44px min-height touch targets)
- Submit button (loading state)
- Error alert (`role="alert"`, auto-focused on error)
- Link to switch page ("Create account" / "Log in")

### 3. Dashboard (Main App)
- Header: Logo + tagline "What changed enough to matter?" + [Log out]
- Hero: "What deserves your attention?"
- Add Symbol Form: Input + Thesis toggle + Add button + optional textarea
- Brief List: BriefCard components (sorted by attention score DESC)
- Mark as Caught Up: Full-width button (bottom of list)

### 4. BriefCard (Individual Stock)
Displays:
- Stock symbol (e.g., "TCS" without .NS suffix)
- Attention badge (dot + score + priority label)
- Freshness badge (Live/Delayed/Stale or Market Closed)
- Price change % (text-2xl, bold, colored green/red)
- "Since checkpoint" label (supporting text)
- Narration (1–2 lines explaining the move)
- Remove button (✕, 44×44px, high contrast)
- ThesisPrompt (if thesis_note exists AND priority HIGH/MEDIUM)

### 5. ThesisPrompt Modal
- Thesis note displayed in quotes
- Question: "Does this move support or challenge that?"
- Three buttons: "Supports it" (green), "Challenges it" (red), "Skip" (muted)
- sessionStorage prevents re-prompting same score in session

## Component Quality Bar

All interactive components must have:
- ✅ 44px minimum touch targets
- ✅ Visible focus rings (not outline: none)
- ✅ Smooth transitions (150–200ms ease-out)
- ✅ Hover effects (lift, color shift, or both)
- ✅ Active state feedback (scale 0.97)
- ✅ Accessible labels (aria-label, aria-pressed, role="alert")
- ✅ Responsive typography + padding
- ✅ Dark theme shadows + contrast

## Interaction Patterns

1. **Add Symbol:** Input text → optional toggle → textarea (if toggled) → Add button
2. **View Brief:** List sorted HIGH→MEDIUM→LOW by attention score. Each card shows score + freshness.
3. **Thesis Prompt:** On HIGH/MEDIUM items with thesis, ask: "Support/Challenge/Skip?"
4. **Mark Caught Up:** Button posts checkpoint for all symbols. Next visit shows delta from baseline.
5. **Remove Stock:** ✕ button on card, no confirmation.

## Responsive Breakpoints

- **Mobile:** <640px — single column, full-width cards, 16px body
- **Tablet:** 640px–1024px — single column, max-width 600px, centered
- **Desktop:** >1024px — single column, max-width 640px, centered (financial apps favor narrow focus)

## Accessibility Requirements

- WCAG 2.1 AA compliance
- Focus ring always visible (2px solid, proper offset)
- Color + text labels (not color-alone semantics)
- Error messages: `role="alert"`, `tabindex="-1"`, auto-focused
- Keyboard navigation: Tab/Shift+Tab, Enter/Space to activate
- No auto-dismiss alerts
- Screen reader support for badges ("95 Attention, HIGH priority")
- Minimum 16px body font
- Color contrast ≥4.5:1 on all text

## Brand Personality

- **Tone:** Clear, direct, honest. No hype.
- **Visual Tone:** Minimal, precise. Whitespace is intentional.
- **Emotion:** Calm confidence. Users are in control.

## Known Constraints

- yfinance ~15–20min delay (disclosed in freshness badge)
- No push notifications yet
- Mobile-first not prioritized; responsive web is primary
- Native mobile Phase 1.5
