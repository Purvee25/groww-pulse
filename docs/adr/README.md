# Architecture Decision Records

This directory contains Architecture Decision Records (ADRs) for Groww Pulse — lightweight documents capturing the key technical choices made during the build, why they were made, and what was rejected.

|---|----------|--------|

| [004](004-trading-hours-elapsed-time.md) | Trading-Hours Elapsed Time for Z-Score | Accepted |

## Format

Each ADR contains: **Context** (problem), **Decision** (what we chose), **Alternatives Considered** (what we rejected and why), **Consequences** (tradeoffs accepted).
